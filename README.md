# Installation

## Clone the repository

```bash
git clone https://github.com/your-username/mini_ecommerce.git
```

## Open project folder

```bash
cd mini_ecommerce
```

## Install dependencies

```bash
npm install
```

## Run the project

```bash
npm start
```

# Usage

1. Open the application
2. Browse products
